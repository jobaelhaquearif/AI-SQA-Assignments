## Q1. What is Software Quality Assurance (SQA)? Define SQA Explain why quality is important in software development. Answer: SQA is a planned, systematic set of activities that ensure software meets defined quality standards.

SQA focuses on ensuring quality throughout the development process and
minimizing defects by addressing potential problems early, rather than
relying solely on testing the completed software. Software quality is
important because it builds customer trust, protects business revenue,
improves user satisfaction, supports security and compliance, and
reduces long-term maintenance cost.

## Q3. How is AI changing Software Testing?

AI is changing software testing by making the testing process more
intelligent, efficient, and reliable. It helps improve software quality
by supporting different testing activities throughout the Software
Development Life Cycle (SDLC).

From Scripted to Intelligent: Traditional automation follows fixed
scripts. AI-driven testing understands intent, adapts to change, and
learns from past runs.

Self-Healing Automation: When a locator breaks due to UI changes, AI
automatically finds the new element and updates the test, reducing
maintenance.

AI Across the SDLC: AI now assists in requirement analysis, test case
generation, Code review, execution, and defect triage—not just
execution.

Intelligent Reporting: AI summarizes failures, clusters similar defects,
and highlights root causes instead of raw pass/fail logs.
